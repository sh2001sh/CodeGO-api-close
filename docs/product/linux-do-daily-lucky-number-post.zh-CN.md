## 活动怎么玩

购买带有每日幸运号权益的月卡后，会获得：

- 一个永久唯一的月卡编号，例如：`PRO · CG-7K2M9Q-7316`
- 一个四位幸运尾号，例如：`7316`
- 按月卡等级赠送的周期盲盒

每天默认 20:00（Asia/Shanghai）全站统一开奖一个四位号码。系统会从右向左匹配连续尾号，只领取最高匹配档，不重复叠加。

| 匹配结果 | 基础奖励 |
| --- | ---: |
| 未中奖 | $0 |
| 匹配 1 位 | $1 |
| 匹配 2 位 | $10 |
| 匹配 3 位 | $50 |
| 匹配 4 位 | $100 + 累计奖池 |

以上是基础奖励，实际奖励会根据月卡等级计算：

- Lite：1.0 倍
- Standard：1.1 倍
- Pro：1.2 倍
- Ultra：1.3 倍

比如 Pro 月卡尾号是 `7316`，当天开奖号码是 `5816`，匹配到最后两位，基础奖励为 `$10 × 1.2 = $12`。

## 累计奖池

- 初始奖池：$100
- 当天无人四位全中：奖池增加 $20
- 奖池上限：$1,000
- 四位全中时，除 `$100 × 月卡等级系数` 外，还会平分当天累计奖池
- 产生四位全中后，下一期开奖奖池重置为 $100

奖励会直接进入中奖的对应月卡额度，不进入普通钱包，也不能提现、交易或转赠。

## 月卡盲盒权益

每个新的月卡计费周期会按等级赠送盲盒：

- Lite：1 个
- Standard：2 个
- Pro：3 个
- Ultra：5 个

续费会进入新的周期并重新赠送；同周期升级只补发新旧等级之间的差额，不会重复发放。

## 几个需要注意的规则

1. 只有开奖快照时处于有效状态、且开启每日幸运号权益的月卡会参与当天开奖。
2. 开奖时间之后购买的月卡，从次日开始参与。
3. 多张有效月卡会分别参与，奖励分别进入对应月卡。
4. 月卡失效后，编号和历史记录仍会保留，但不再参与后续开奖。
5. 月卡编号不替代账号 UID，账号、订单和历史记录仍按原有方式管理。
6. 中奖概率和奖励规则会在活动页面公开，实际时间以页面显示为准。
