# 首页：字形、汇流与接入

<a id="P01"></a>
## P01 · 首页 /
使用L-P；实现锚点为features/dawn/home，demo入口index.html。角色为公开访客，目的为探索模型并找到接入。页面配置可能替换原生首页，真实改造应保留现有配置分支。当前demo独立运行。

## 首屏构图
1440：导航76px；品牌区上间距48、下间距32；CodeGo字形clamp(96px,16vw,224px)，字距-.04em，纯色墨黑，最后一个标点铜橙。标题与路由场位于下一行独立区域，12列中标题5列、路由7列，gap32；主标题“智能，自由汇流。”，最多两行，无副标题。探索模型为唯一实底CTA，接入为文字链接。路由场高320px，表头直接标“路由预览”，包括暂停按钮与模型选择；它是机制演示，不呈现真实吞吐量。

1024：品牌最大176px，标题和路由仍双列，各6列。768：品牌128px，标题在前、路由在后，路由高280。375：品牌clamp(80px,22vw,112px)，标题32px，路由240px，主要动作44px以上，表头自然换行。正文不覆盖canvas，节点交互控件放在canvas下方正常流。

## 首页动效编排
M20品牌进入：DOMContentLoaded后，单次opacity .8→1、y 12→0，280ms；字形不会先隐藏，避免脚本失败形成空白。中文标题同时进入，不逐字拖延。链接始终可操作。

M21路由物理场：指针仅在场内影响路径控制点，位移上限16px；mass1、stiffness180、damping26，400ms内收敛；模型切换产生一次280ms路径状态交叉淡入。静态线条承载拓扑，流动点只表示预览。单一requestAnimationFrame循环，限制DPR≤2；后台及离屏暂停。触屏不追踪手指，触发模型选择时只完成一次路径变化。

M22模型筛选：输入防抖180ms，先保持旧内容；结果整体opacity .7→1，180ms。最多首6行错峰40ms；不反复移动行高度。零结果显示“无匹配”及“清除筛选”。搜索、分类和返回详情保留原状态。

M23滚动定位：原生锚点，滚动至章节时不拦截用户滚轮。减少动效时auto；其他场景用浏览器smooth且不绑定滚动强制吸附。区块正文默认可见，不通过动画决定内容是否存在。

M24代码切换：先立即提交新语言及内容，代码区域opacity .75→1，180ms；保留代码区最小行数以免跳动。复制等待真实剪贴板结果，成功“已复制”，失败“复制失败”并保留选中复制入口，2秒后恢复动作名。

详情C23用M03，关闭后恢复具体模型行按钮焦点和滚动。移动菜单C01用M02，不与详情同时打开。暂停操作立即停止循环；重新开启不补播离屏时间。

## 减少动效与失败
prefers-reduced-motion启用后渲染静态线图、没有指针偏移或循环流动点；选择状态即时变化。Canvas创建失败仍保留HTML选择与文本拓扑。JS失效时模型名称、标题、代码样例及链接可阅读。demo不发模型请求、不出现伪造余额、成功订单或SLA。

## 接入片段
Base URL为用户配置；demo初始使用环境变量占位，缺失值明确呈“待配置”。代码使用CODEGO_BASE_URL、CODEGO_API_KEY和MODEL_ID，禁止写实际密钥。复制不触发网络。用户切换模型后保留参数，未核验的展示名不自动冒充实际API ID。

## 素材与收尾
真实CodeGo标志来自public/code-go-logo.svg，32×32全幅。字体使用现有本地woff2。首页代码路由图是功能几何，不借照片或虚构厂商标志填充。禁止旧方案中的虚构订单量、40ms、99.98%、T+0等未经证实承诺。
