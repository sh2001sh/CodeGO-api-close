# 组件库：布局、属性与动效契约

## 统一实现约束
本章是拟议设计契约；名称用于团队沟通，并不声称仓库中已有同名组件。先复用既有components/ui和业务组件，再补足语义和状态。事件仅提交用户意图，真实成功由服务端返回决定。

全部交互控件：默认可读；hover只在支持悬停设备生效并加深；focus使用2px可见轮廓；按压遵循M01；disabled有HTML/ARIA语义且不触发事件。加载只锁定当前提交动作，错误就地显示并保留输入，成功反馈使用真实结果。以下每项列出专属状态和例外。

布局遵循第02章；每个字段和堆叠信息为独立块；主动作标签、价格、时间、状态保持完整。所有颜色和时长来自变量。适用动效ID在第11章给出完整参数、退出与减少动效方案。

## 组合与数据责任
容器组件不自行猜测隐私、能力或价格。C25绑定字段来源，C24绑定实际计费数据，C46区分估算与结算。组件可组合为页面，但不得形成没有消费者的通用框架。
