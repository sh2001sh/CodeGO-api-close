# 公开、账号及错误页面逐页规范

模型目录是否公开由现有配置和路由守卫决定；设计不能把公开视觉当作放宽权限的理由。下列布局均为实施规范。文档页P08在第07章，首页P01在第03章。厂商名称用真实文字，未取得品牌资产时不自造图标。

## P02 · 模型目录

- 路由与状态：`/pricing`；本地源码已有入口，部署状态未核实。
- 角色与主任务：公开，实际受站点模型页开关及登录配置约束；找到模型并核对实际能力。

- 组件：C09 C21 C22 C24 C25 C19。源码锚点：`features/pricing`。

### 布局与内容
1440：最大1184px、12列、gap24px、边距64px。1024：边距32px。768：8列、gap16px、边距24px。375：单列、边距20px、区块隙32px。

### 本页动效
M06搜索180ms防抖，M07结果整体180ms淡入；选择对比即时选中，不让价格跳动。

公共状态引用M01反馈、M05就绪；数据价格及唯一身份保持静态。中断从当前视觉状态继续，旧请求不得覆盖新结果。减少动效时取消位移和循环，状态直接切换，焦点与读屏反馈保留。

### 实施与未来验收
