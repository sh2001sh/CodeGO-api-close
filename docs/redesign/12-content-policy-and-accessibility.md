# 文案、政策与可访问性

## 产品文案硬约束

用户明确禁止前端页面中的描述性文本、解释性副标题和引导性小字；禁止含“不是”的转折句。此规则覆盖首页、模型卡片、导航、对话和后台，不只限制首屏。长解释保留在设计方案与独立阅读文档中。产品保留任务必需的标签、字段、实际数据、状态、错误、法律正文与明确确认后果；不以“提示”“说明”名义重塞营销小字。

| 区域 | 采用 | 禁止 |
| --- | --- | --- |
| 首页主视觉 | 智能，自由汇流。 | 标题下再解释一段产品优势 |
| 主操作 | 探索模型、接入、复制 | 模糊的了解更多、开始奇妙旅程 |
| 模型 | 真实名称、提供方、示例/待接入状态 | 虚构稳定性/零保留/极低延迟 |
| 输入 | 常驻label“搜索模型”“Base URL” | 仅靠placeholder说明用途 |
| 状态 | 待核验、处理中、已取消、失败 | 未确认到账即显示成功 |
| 错误 | Base URL须使用http或https；可修改后重试 | 出错了、invalid input |
| 详情 | 可读的字段与来源状态 | 功能尚未接入却写已支持 |
| 页脚 | 品牌、真实导航、已配置政策入口 | 编造运营主体、联系邮箱、SLA |

本轮demo不展示营销段落。字段值“示例”“待接入”明确真实性；为减少产品界面解释密度，项目和事实边界完整写入本方案与阅读入口。必要表单错误以常规16px就地反馈，不写成细小页脚。

## 文本长度、换行与数据

 authored标题、按钮、标签按容器长度写，不截断：筛选词≤4汉字、按钮单行、tile名≤5汉字；实际模型全名属于数据，可列表截断但必须点击可读全名。详情、订单、确认和政策正文完整换行。价格/时间/数量/状态/主操作/错误不得截断；numeral与unit使用nowrap。空间不足就减少副列、换布局，不缩小字号挤下。

每一信息一块：label/helper，weekday/date，numeral/caption分别block；不把两个span默认为inline。长model ID、URL、requestId在详情可overflow-wrap:anywhere，代码在专用区域横滚。CJK只在短语边界wbr，不让两字词拆开。用户数据必须HTML转义，禁止innerHTML拼未清洗数据。

## 政策与支持的真实来源

上线前由运营/法务提供并确认：运营主体及地区、收费币种与单位、发票资质、退款资格与限制、支持渠道/时间、删除方式与实际可删范围、日志/对话/图像/支付信息各自保留期、第三方处理者及传输范围、政策版本及生效日。

保留期未知显示未知，不能承诺零保留。供应商声明与本站实际处理策略分开，个人清除localStorage不等于服务端删除记录。删除请求给可核实的申请ID与真实状态；法定/财务必要记录按实际政策单列。尚缺以上事实时，方案写“待确认”，业务入口不先承诺自动退款、分钟响应或任何时效。

公开支持的八主题文档需建立可信联系人来源；未配置不生成假邮箱或社群二维码。导出工单材料默认去除token/secret/完整个人信息，保留requestId、时间、模型/分组、错误码。用户主动授权才附加提示与输出。

## 可访问性契约

- body≥16px、line-height1.6，正文65–75ch，手机35–60ch；英文显示字体与中文回退均有明确font-family。系统缩放200%仍正常流，不锁死正文高度。
- 正文对比≥4.5:1、大字/图标/关键图形≥3:1。暖白/铜橙来自既有品牌，不是基线默认配色；正文用#221F1C，次要文字#6F665E；装饰橙#D26739不承担小字或关键边界。深色独立使用#FAF7F3/#171411及#F3A27F强调。
- 所有功能用button/a/input/select等原生语义。focus-visible为2px实线加4px偏移，主题适配；禁止outline:none。点击区域至少44px，触屏操作不依赖hover。
- 页首跳到主内容；header/nav/main/footer和section标题层级正确，每页一个主h1。整行跳转用a并设color与text-decoration，不混入不可达伪链接。
- 当前导航用aria-current，切换按钮用aria-pressed或原生select。披露aria-expanded；dialog有标题、关闭、焦点圈定和还焦；背景inert。模态内容过长自身滚动且关闭控件可达。
- 所有表单有常驻label，必填有文本标记；blur校验，提交时显示错误摘要链接与就地原因/修复动作。复杂项渐进展开。错误不只靠红色，加载不只靠旋转。
- 图表有同值列表，canvas仅装饰；状态图标配文本。图像有真实alt；装饰图标aria-hidden。无需读出每个流式Token或每帧粒子。
- live区域只播复制、提交与结果摘要。加载aria-busy；无确定总量的任务不写aria-valuenow；有总量用真实值。页面结果变更保留焦点，关键失败可role=alert。
- prefers-reduced-motion关闭位移、弹簧、平滑滚动与循环。首页暂停保留已选路由；离屏及后台暂停。触屏静态拓扑仍完整，不依赖拖拽才能选路。

## 国际化与日期

开发者文档七语言入口zh-CN/zh-HK/en/fr/ru/ja/vi；缺译保留主题并标原文，不用空页面。产品demo默认简体中文，语言代码是接入代码语言，与UI locale分开。金额/时间用真实币种及时区，日期格式可本地化但订单精度不能改变。列表排序不依赖中文显示名替代稳定ID。

## 失败与空状态写法

无模型：无匹配模型＋重置。网络失败：加载失败＋重试；保留现有筛选与最近数据。权限不足：无权访问＋返回可访问区域。未发布功能：待接入，不保留假可点击动作。未知数据：待核验＋来源详情。删除前列对象、数量和实际后果，失败保留记录，不先从UI假删。

## 说明边界

本设计文档允许详细解释，产品文案严格精简。API错误、表单错误、账务必要事实、政策阅读正文有实际任务目的，但不能扩展为每块组件都附一段说明。无法兼顾时，优先改信息结构：字段值、状态、按需详情和专门阅读页。
